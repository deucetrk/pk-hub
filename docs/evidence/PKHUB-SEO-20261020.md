## Automatic search-engine notification — 2026-10-21

- `.github/workflows/indexnow.yml` runs after each push to `main` that touches `website/`. It waits
  until `pkhub.co/revision.json` serves that commit, then submits to IndexNow (Bing, which feeds
  ChatGPT search and Copilot, plus Yandex, Naver and Seznam) every sitemap URL with a `lastmod` in
  the last 14 days. A manual run with `all` submits every URL. The key file is
  `website/public/a8f8fad4c901e7c7fcdd8102cb929bc8.txt`; it is public by design.
- The sitemap now carries `lastmod` only where the content date is known: articles, and the blog
  index as its newest article. Before this, every page carried the build date, which teaches
  search engines to ignore `lastmod`.
- Google takes no IndexNow, and its sitemap ping was retired. It discovers new articles from the
  sitemap and the blog index. A Search Console "Request indexing" only speeds that up.
